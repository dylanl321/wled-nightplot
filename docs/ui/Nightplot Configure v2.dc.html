Nightplotconfigure · v2 direction

The strip is the interface. Everything else is a margin note.

Instead of pages about a Light, one workspace where the glowing row stays put and you change what you’re doing to it. v1 is kept as the conservative baseline.

Modes, not tabsInspect · Edit ranges · Test live act on one persistent strip picture.
Two rails of truthDeclared brackets above the beads, reported below. Drift is a visible gap.
Proof ladderSent → Controller reports → You saw it. The last rung is always a person.
All Off has a homeBottom of the rail (desktop) or thumb bar (phone). Confirm expands in place.
Blink before you addDiscover lets you pulse a candidate so you know which box it is.
Live session barTemporary output is a visible, timed session — never a hidden state.
